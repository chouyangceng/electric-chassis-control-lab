# 中文说明

## 项目用途

本项目用 7 自由度车辆模型描述车身纵向、横向、横摆和四个车轮旋转状态，再研究四轮电机如何分配扭矩来控制横摆和侧偏。

## 代码对应关系

- `models/vehicle7dof.py`：车身、轮速和载荷转移近似；
- `models/tire.py`：纵横向联合滑移与摩擦圆约束；
- `controllers/dyc.py`：直接横摆力矩控制；
- `controllers/lqr.py`：线性二次型控制基线；
- `controllers/nmpc.py`：小预测窗的非线性控制基线；
- `allocation/qp_allocator.py`：四轮扭矩限幅和横摆力矩分配；
- `experiments/runner.py`：双移线、低附着和电机降级场景。

## 运行与解释

先运行 `python examples/quickstart.py`。`yaw_rate_rmse` 越小表示横摆响应越接近目标，`sideslip_peak` 越小表示侧偏峰值越低，`torque_saturation` 表示执行器达到扭矩边界的比例。实际车辆还需要轮胎参数、质量、质心和电机标定。
